Host this entire app globally on Cloudflare with zero server costs

1 Get the Web App Code

If your browser blocks the download button, tap "Copy Full Code" to save the entire application straight to your tablet's clipboard.

2 Log in to Cloudflare Dashboard

Go to dash.cloudflare.com (create a free account if you don't have one).

3 Drop & Deploy via Cloudflare Pages
  • In the left sidebar, click Compute (Workers & Pages).
  • Click Create Application → Select Pages tab.
  • Choose "Upload assets".
  • Give your project a name (e.g. my-creature-forge).
  • Drag and drop the folder containing your index.html file or the file itself into the upload box.
  • Click Deploy site.
Done! You will get an instant live URL

Cloudflare will deploy it across 300+ global data centers and give you a free SSL URL like https://my-creature-forge.pages.dev with unlimited bandwidth.
